# Production roadmap

## Phase 1
- Firebase Authentication
- Firestore products/categories/orders
- Firebase Storage for product images
- Admin web panel
- Seller registration and approval
- Product approval workflow

## Phase 2
- COD order workflow
- Seller order dashboard
- Stock management
- Push notifications
- Delivery fee rules by district

## Phase 3
- Reviews/wishlist
- Coupons
- Analytics
- Courier integration
- Optional compliant online payment gateway

## Health-product safeguards
- Store manufacturer, batch/lot, expiry, ingredients, pack size and warnings.
- Verify required Sri Lankan regulatory registration/authorization before listing regulated products.
- Avoid unsupported disease-cure claims.
