# කෝලිත ඔසු නිවස / Kolitha Osu Niwasa

Bilingual Flutter starter app for a Sri Lankan Ayurveda/herbal marketplace.

## Included in this starter
- Sinhala + English UI toggle
- Nature-inspired Kolitha Osu Niwasa logo
- Home, Categories, Product Details, Cart, Checkout, Orders, Profile
- Cash on Delivery checkout
- Islandwide delivery field
- Sample product catalog
- Basic cart state
- Seller/Admin roadmap in `ROADMAP.md`

## Run
1. Install Flutter SDK.
2. Extract this folder.
3. Run `flutter pub get`.
4. Run `flutter run`.

This is a frontend starter. Production deployment still needs a backend, authentication,
real product database, seller onboarding, order management, delivery integration, and
regulatory review for products that are legally regulated as medicines.
